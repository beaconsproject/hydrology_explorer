### Set feature to track

In this step, the user specifies the source for a spatial layer to track (e.g. fire) on which spatial statistics will be calculated. 

**Select source of the feature to track** offers three options: 

1. **Use existing fire layer** - If a Disturbance Explorer GeoPackage was uploaded in the previous step, the app lists all potential feature layers. 
   
2. **Upload feature layer** - If selected, the user can upload a feature layer as shapefile or GeoPackage.

3. **No feature to track** - No feature is tracked (default).

If No feature to track is selected, the **Feature statistics** table will not populate.

Press the **Confirm** button. The feature layer will appear on the map, and related statistics will be calculated in the Feature Statistics section.
