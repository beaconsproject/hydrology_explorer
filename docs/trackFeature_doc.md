### Set a feature to track

In this step, the user specifies the source for a spatial layer to track (e.g. fire) on which spatial statistics will be calculated. 

**Select source of the feature to track** offers three options: 

1. **Use existing fire layer** - If a Disturbance Explorer GeoPackage was uploaded in the previous step, it may include a fire layer. 
   
2. **Upload feature layer** - If selected, the user can upload a shapefile or GeoPackage of the fire spatial layer.

3. **No feature to track** - No feature is tracked (default).

If No feature to track is selected, the **Feature statistics** table will not populate.

Press the **Confirm** button. If an intactness layer is provided, it will be displayed on the map.
